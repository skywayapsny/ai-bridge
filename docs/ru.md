# AI Bridge

Подключи своё AI-приложение к мосту как к провайдеру Chat Completions.
Devin, Claude Code, Codex или другой агент может забрать реальный запрос,
посмотреть историю сообщений и схемы инструментов и вернуть ответ.
Если агенту доступен репозиторий приложения, он может сверить фактический
запрос с кодом. Для ошибок, которые происходят до или после вызова модели,
приложению или окружению агента нужно предоставить очищенный лог.

Самый простой сценарий — отправить тестовый запрос с тегом `debug`,
забрать его командой `ai-bridge-agent claim --model debug` и ответить
через `ai-bridge-agent respond`. С помощью заготовленных ответов можно
проверить парсер, tool calls и таймауты без платного вызова модели.
Использование внешнего агента и upstream-модели учитывается их провайдерами.
